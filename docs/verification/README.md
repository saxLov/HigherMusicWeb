## 2.0.1 回归检查

- 付费资源status=1、会员有效、权益接口失败但音源完整时，均不会把未知权益提升为已授权。
- 免费字段null、空串、布尔值不作为明确免费证据；不同MixSongID或专辑的候选不借用，音源响应版本不符拒播。
- 八秒中断、自动恢复后再听八秒，保留轮次和累计时间且只提交一次；自动定位与用户拖动有独立测试。
- 已达标记录排在慢检查之后，正常下一首仍提交原歌曲；关开关和退出取消未发任务。
- 顶部重新检查会请求所有歌曲，首项刷新账号缓存；继续检查仍只处理未完成部分。
- 平台缺失成功状态、显式拒绝、请求体读取期间退出等情况不会标记已接受；同轮次不盲目重试。

当前未实现会员覆盖范围的可靠映射，因此没有明确购买或免费证据的会员歌曲显示待确认。真实账号是否在手机端显示历史，留待用户上手测试。
